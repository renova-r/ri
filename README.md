# ri

Randomization-based inference for experiments of arbitrary design: permutation matrices implied by the design, average treatment effect estimation, constant-effects variance estimation and randomization tests of sharp null hypotheses.

Compatibility updates by Renova.

Version 0.9.9001 declares the `graphics`, `stats` and `utils` functions it uses in `NAMESPACE` and writes a DOI reference in two help pages with the `\doi{}` macro. No R code or `DESCRIPTION` field was changed.

## Install

Install this release from its GitHub tag:

```r
install.packages("remotes")
remotes::install_github("renova-r/ri@renova-0.9.9001")
```
